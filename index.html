AI Agent

DOC Agent

An AI-powered architecture & API documentation assistant. Upload PDF/DOCX docs and ask questions in plain English — the agent retrieves the right chunks and answers with cited sources, page numbers, and relevance scores.

  • Ingests PDFs/DOCX (PyPDFLoader, Docx2txtLoader), chunks with a RecursiveCharacterTextSplitter (512-char chunks, 50-char overlap), and embeds locally via HuggingFace all-MiniLM-L6-v2 — persisted in a local ChromaDB store.
  • On query: embeds the question, retrieves the top-5 similar chunks from ChromaDB, and generates the answer via the Groq API (Llama-3.3-70b-versatile).
  • Hybrid local/cloud design — documents, chunking, and embeddings never leave the local machine; only the retrieved-context prompt goes to Groq.
  • Tracks ingested files (ingested.json) to avoid duplicate re-ingestion, and logs every query (queries.jsonl) for observability and audit.
